# SPX / NDX 大型回撤成因与可预测性研究（2011–2026）

检测并归因 S&P 500 与 Nasdaq 100 过去 15 年的大型回撤事件（单日 > 1.3%、单周 > 3%），
检验宏观日历押注、期权 gamma 流、波动率聚集等假说，并用严格无前视的走向式回测
评估"提前一天预知"的真实可行边界。

**旗舰深度报告（含11张图表）见 [DEEP_RESEARCH_REPORT.md](DEEP_RESEARCH_REPORT.md)。**

其余文档：研究结论 [REPORT.md](REPORT.md)；数据与信号库设计 [SIGNALS.md](SIGNALS.md)；体系汇报 [SYSTEM_REPORT.md](SYSTEM_REPORT.md)。

- `src/` — 可复现的分析脚本（数据下载、事件识别、日历归因、前兆分析、预测回测、图表）
- `data/` — 缓存的市场数据（Yahoo Finance）
- `output/` — 事件清单与统计结果 CSV
- `figures/` — 报告图表
